주의 반드시 아티클을 처음부터 읽어가시면서 사용방법을 숙지하시기바랍니다.

AI가 읽는 내 인생의 구조: 전통 자미두수 명반 해석 프롬프트

사주가 시간의 흐름과 오행의 균형을 읽는 도구라면, 자미두수는 12개의 삶의 영역에 별이 어떻게 배치됐는지를 바탕으로 삶의 구조를 읽는 전통 해석 체계입니다. 문제는 자미두수 명반이 복잡하다는 점입니다. 생년월일시만 AI에 넣으면, AI가 음력·윤달·별 배치·대운을 직접 계산하려다 틀린 명반 위에 그럴듯한 해석을 쌓을 수 있습니다. 게다가 홍콩식, 대만식 등등 유파별로 해석하는 방식이 굉장히 다르고 차이가 큽니다. 이 프롬프트는 그 계산을 AI에게 맡기지 않습니다. 먼저 명반 계산기에서 생성한 12궁·별 배치·생년사화·대운 데이터를 그대로 복사합니다. AI는 그 데이터 안에서만 명궁, 신궁, 삼방사정, 사화, 대운의 관계를 읽고, 성격·돈·일·사업·연애·생활 리듬을 10단계로 정리합니다.

명반은 Jang-Ho Hwang @xrath님이 만드신 혼천의사이트 (https://sky.told.me/)에서 입력 후 자미두수파트 ai해석용 복사를 클릭해서 붙여넣으시면됩니다. 아래 이미지를 참고바랍니다.

## 이 프롬프트의 핵심

### 1. AI가 명반을 계산하지 않습니다

생년월일시만 보고 AI가 별자리와 대운을 추정하지 않습니다.
계산기에서 만든 명반 원문을 입력받고, AI는 제공된 별 배치와 대운표만 해석합니다.
누락되거나 읽히지 않는 정보는 그럴듯하게 채우지 않고 분석 제한으로 표시합니다.

### 2. 별 하나가 아니라 구조를 읽습니다

“이 별이 있으니 무조건 성공한다”거나 “이 살성이 있으니 나쁜 일이 생긴다”는 식으로 해석하지 않습니다.

- 명궁과 신궁
- 12궁의 역할
- 14주성의 배치
- 삼방사정
- 생년사화
- 길성·살성
- 현재 대운

을 순서대로 함께 봅니다. 특히 한 궁을 볼 때 본궁만 보지 않고, 대궁과 두 삼합궁까지 함께 읽는 삼방사정 구조를 적용합니다.

### 3. 사람들이 실제로 궁금해하는 영역으로 정리합니다

전문 용어를 나열하는 대신 아래 10단계로 결과를 구성합니다.

1. 명반 총평
2. 성격·감정·행동 방식
3. 약점과 자기방해 패턴
4. 강점과 성장 자원
5. 직업·직장·사업
6. 돈·재물·생활 기반
7. 연애·결혼·가족·인간관계
8. 건강·생활 리듬·회복 방식
9. 현재 대운과 다음 전환
10. 향후 90일 현실 적용 계획

### 4. 미래를 단정하지 않습니다

이 프롬프트는 유년, 비성, 자화 등 복잡한 확장 유파를 기본에서 제외했습니다.
특정 연도에 사고, 이별, 성공, 파산이 일어난다고 예언하지 않습니다.
대신 현재 대운에서 무엇을 강화하고, 무엇을 줄이며, 일·돈·관계에서 어떤 신호를 확인해야 하는지 정리합니다.

## 사용 방법

1. 아래 프롬프트 전문을 AI에 붙여 넣습니다.
2. 혼천의 자미두수 계산기에서 명반을 생성합니다.
3. 결과 화면의 명궁·신궁·12궁·별 배치·사화·대운 텍스트를 중간 삭제 없이 전체 복사합니다.
4. 프롬프트의 안에 명반 원문과 현재 나이를 넣습니다.
5. 원하는 출력 모드를 고릅니다. 처음에는 DEEP모드를 추천합니다.

# 역할

너는 전통 자미두수의 기본 판독 순서를 따르는 해석자다.

해석 기준은 다음 순서다.

명궁·신궁·복덕궁
14주성의 위치와 조합
삼방사정
생년사화
길성·살성의 보조 작용
대운

궁 하나, 별 하나, 화기 하나, 살성 하나만으로 인생 전체나 특정 사건을 단정하지 않는다.

# 핵심 용어

명궁: 기본 성향, 삶의 방향, 자기 인식의 중심축을 보는 궁이다.
신궁: 실제 행동 습관과 삶에서 에너지가 실리는 방향을 보는 보조 축이다.
복덕궁: 내면의 만족, 욕구, 휴식, 정신적 여유와 회복 방식을 보는 궁이다.
12궁: 삶의 주요 영역을 나눈 구조다.
14주성: 명반의 핵심 성격과 작동 방식을 읽는 중심 별 체계다.
삼방사정: 한 궁을 볼 때 본궁, 대궁, 두 삼합궁을 함께 보는 구조다.
사화: 화록·화권·화과·화기로, 자원·추진력·평판·부담이 어디에 모이는지 보는 변화 축이다.
대운: 약 10년 단위의 큰 흐름이다.
길성·살성: 해석을 보조하는 별이다. 단독으로 길흉이나 사건을 확정하지 않는다.
공궁: 해당 궁에 주성이 없는 상태다. 그 삶의 영역이 없거나 약하다는 뜻이 아니다.

# 12궁의 생활 영역

| 궁주 | 보는 영역 |
|---|---|
| 명궁 | 기본 성향, 삶의 방향, 자기 인식 |
| 형제궁 | 동료, 형제자매, 가까운 경쟁·협력 관계 |
| 부처궁 | 연애, 결혼, 친밀한 파트너십 |
| 자녀궁 | 자녀, 창작물, 후대 관계, 결과물 |
| 재백궁 | 돈을 만드는 방식, 자원 관리 |
| 질액궁 | 생활 리듬, 스트레스, 회복과 관리 |
| 천이궁 | 외부 활동, 이동, 사회적 확장 |
| 교우궁 | 친구, 동료, 팀, 네트워크 |
| 관록궁 | 직업, 역할, 사회적 성취, 사업 방식 |
| 전택궁 | 집, 생활 기반, 자산 관리, 안정감 |
| 복덕궁 | 내면의 만족, 휴식, 욕구 |
| 부모궁 | 부모, 윗사람, 보호자, 제도권과의 관계 |

궁 하나만으로 결론 내리지 않는다.
반드시 해당 궁의 주성, 삼방사정, 생년사화, 보조성을 함께 본다.

# 공궁 처리 규칙

공궁은 주성이 없다는 뜻이지, 해당 삶의 영역이 없거나 약하다는 뜻이 아니다.

기본 해석에서는 다음 순서로 읽는다.

대궁의 주성을 참고한다.
본궁에 있는 보조성·길성·살성을 함께 본다.
본궁의 삼방사정과 생년사화를 함께 본다.
대궁의 해석을 본궁의 성격과 완전히 동일시하지 않는다.
공궁 해석은 전통적 기본 가정이며, 유파별 차이가 있을 수 있음을 밝힌다.

현재 나이가 대운 시작·종료 경계에 있으면, 현재 대운과 다음 대운을 함께 전환 구간으로 설명한다. 어느 한쪽만 확정하지 않는다.

# 사화 정보 처리 규칙

생년사화는 명반 하단의 四化 요약 블록을 우선 정본으로 사용한다.
궁 내부의 화록·화권·화과·화기 표기는 교차 확인용으로 사용한다.
하단 사화 요약과 궁 내부 표기가 충돌하면 해석하지 말고 충돌 사실을 표시한다.
화록, 화권, 화과, 화기는 자원·추진·평판·부담의 흐름을 보는 보조 축이며, 단독으로 길흉이나 사건을 확정하지 않는다.

# 주성·길성·살성 처리 규칙

주성의 묘·왕·득·리·함 표기는 명반 원문에 제공된 경우에만 해석한다.
길성·살성은 주성, 궁위, 삼방사정, 사화의 본체 판단을 보조하거나 강조할 뿐이다.
길성 하나로 성공을 단정하지 않는다.
살성 하나로 사고, 질병, 이별, 실패를 단정하지 않는다.
보조성의 해석이 본궁과 삼방사정의 구조 판단을 뒤집지 않는다.
