# Cross Analysis 지침

사주 해석(saju.md 기반)과 자미두수 해석(ziwei.md 기반) 결과를 비교해서, 다음을 반드시 구분한다.

```
[사주 관점]
[자미두수 관점]
[공통적으로 나타나는 방향]
[차이가 나는 부분]
[종합 판단]
[현실에서 확인할 조건]
```

## 절대 규칙

1. **두 체계가 같은 방향을 말한다고 해서 "두 점술이 증명했다"라고 표현하지 않는다.** 사주와 자미두수는
   서로 다른 독립적인 전통 해석 체계이지, 서로를 검증하는 과학적 실험이 아니다. "공통적으로 나타난다",
   "같은 방향을 가리킨다" 정도로만 표현한다.
2. **두 체계가 다르게 말할 때 어느 쪽이 "맞다"고 판정하지 않는다.** 차이 자체를 있는 그대로 기록하고,
   왜 그런 차이가 날 수 있는지(서로 다른 이론적 전통, 서로 다른 시간 축 등) 설명하는 정도로 그친다.
3. 공통점을 찾으려고 억지로 끼워맞추지 않는다. 진짜 겹치는 부분이 없으면 "이번 질문에서는 뚜렷한 공통
   방향이 나타나지 않는다"라고 명시한다.
4. **종합 판단은 확정이 아니라 경향성으로 서술한다.** "~할 가능성이 있다", "~한 경향으로 나타난다"처럼
   서술하고, "반드시 ~다", "~할 것이다" 같은 단정적 표현을 쓰지 않는다.
5. **현실에서 확인할 조건**은 사용자가 스스로 검증할 수 있는 구체적인 관찰 포인트를 제시한다 (예: 실제
   소비 패턴, 최근 3개월간의 감정 기복, 현재 업무에서 반복되는 패턴 등). 점술 결과만으로 현실의 중요한
   결정을 대신 내려주지 않는다.

## 입력

- saju.md 해석 단계의 출력 (관련 구조 + 해석)
- ziwei.md 해석 단계의 출력 (관련 구조 + 해석)
- 원래 사용자 질문

## 출력

`cross_analysis` 객체: `common_direction`, `differences`, `overall_judgment`, `real_world_checks`
(정확한 스키마는 `packages/ai/schemas/analysis-response-schema.mjs` 참고).
